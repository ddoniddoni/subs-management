# 화면 구성도 - Subscription Ops Console

이 문서는 **TeamFit / Subscription Ops Console** 프로젝트의 초기 화면 구성을 정리합니다.

이 문서의 목적은 README, 실행 계획 문서, 이후 작업이 일관된 기준 위에서 진행되도록 하는 것입니다.

---

## 공개 / 고객용 화면

### 1. 랜딩 페이지 `/`
**목적**
- 가상의 구독 서비스를 빠르게 설명합니다.
- 관리자 콘솔이 필요한 비즈니스 맥락을 보여줍니다.
- 사용자가 요금제 선택으로 이동하도록 유도합니다.

**구성**
- 히어로 섹션
- 핵심 가치 소개 섹션
- 요금제 미리보기 카드
- FAQ 미리보기
- 요금제 페이지로 이동하는 CTA

**메모**
- 이 페이지는 의도적으로 가볍게 유지합니다.
- 초기에 장식적인 마케팅 완성도에 과하게 투자하지 않습니다.

---

### 2. 요금제 페이지 `/pricing`
**목적**
- 플랜 차이를 명확하게 비교합니다.
- 가격, 결제 주기, 기능 차이를 전달합니다.

**주요 UI**
- 요금제 카드
- 결제 주기 라벨
- 기능 비교 목록
- 플랜별 CTA

---

### 3. 체크아웃 페이지 `/checkout`
**목적**
- 구독 구매 흐름을 목업 형태로 보여줍니다.

**주요 UI**
- 선택한 플랜 요약
- 고객 정보 입력 폼
- 목업 결제 수단 폼
- 주문 요약
- 성공 상태

**메모**
- v1에서는 실제 결제 연동이 필요하지 않습니다.
- 이 흐름은 전체 제품 시나리오를 뒷받침하는 용도로 둡니다.

---

### 4. 내 구독 `/app/subscription`
**목적**
- 현재 플랜과 구독 상태를 보여줍니다.

**주요 UI**
- 현재 플랜 카드
- 상태 배지
- 갱신일 / 만료일 정보
- 플랜 메타데이터
- 최근 활동 요약(선택)

---

### 5. 결제 내역 `/app/billing`
**목적**
- 청구서와 결제 시도를 명확하게 보여줍니다.

**주요 UI**
- 결제 내역 테이블
- 청구서 번호
- 금액 / 날짜
- 결제 상태 배지
- 실패 / 환불 표시

---

## 관리자 / 운영 대시보드

### 6. 관리자 홈 `/admin`
**목적**
- 내부 운영자가 빠르게 전체 현황을 파악할 수 있게 합니다.

**주요 UI**
- KPI 카드
- 매출 / MRR 차트
- 결제 실패 요약
- 환불 대기 요약
- 최근 활동 또는 알림

---

### 7. 고객 목록 `/admin/customers`
**목적**
- 고객을 빠르게 검색하고 필터링할 수 있게 합니다.

**주요 UI**
- 검색 입력창
- 상태 필터
- 플랜 필터
- 정렬 가능한 테이블
- 페이지네이션

**권장 컬럼**
- 고객 이름
- 이메일
- 플랜
- 구독 상태
- 다음 결제일
- 최근 결제 상태

---

### 8. 고객 상세 `/admin/customers/[customerId]`
**목적**
- 한 명의 고객에 대한 운영 정보를 한곳에서 보여줍니다.

**섹션**
- 고객 프로필 요약
- 구독 요약
- 결제 내역
- 환불 이력
- 쿠폰 이력
- 감사 타임라인

**주요 액션**
- 구독 일시중지
- 구독 재개
- 구독 해지
- 쿠폰 발급
- 환불 검토 시작

---

### 9. 결제 `/admin/payments`
**목적**
- 결제 상태를 확인하고 실패 건에 대응할 수 있게 합니다.

**주요 UI**
- 상태 필터
- 결제 실패 영역
- 확인 절차가 포함된 재시도 액션
- 결제 상세 드로어 / 모달
- 고객 상세 페이지로 돌아가는 링크

---

### 10. 환불 `/admin/refunds`
**목적**
- 환불 요청을 안전하게 처리합니다.

**주요 UI**
- 요청 / 승인 / 반려 상태별 뷰 또는 필터
- 요청 상세 패널
- 승인 액션
- 사유 입력이 포함된 반려 액션
- 처리 후 감사 로그 기록

---

### 11. 쿠폰 `/admin/coupons`
**목적**
- 할인, 리텐션 오퍼, 보상성 혜택을 관리합니다.

**주요 UI**
- 쿠폰 목록
- 쿠폰 발급 모달
- 쿠폰 회수 액션
- 상태 / 만료일 필터

---

### 12. 분석 `/admin/analytics`
**목적**
- 운영 관점에서 중요한 추이를 보여주고 판단에 도움을 줍니다.

**주요 UI**
- MRR / 매출 추이
- 활성 구독 추이
- 이탈 요약
- 결제 실패율
- 환불 비율

**메모**
- 차트는 장식이 아니라 의사결정에 도움이 되어야 합니다.

---

### 13. 관리자 사용자 `/admin/admin-users`
**목적**
- 역할별 접근 범위와 권한 구조를 보여줍니다.

**주요 UI**
- 관리자 목록
- 역할 배지
- 권한 요약
- v1에서는 읽기 전용 화면도 허용 가능

---

### 14. 감사 로그 `/admin/audit-log`
**목적**
- 중요한 운영 변경 사항을 추적 가능하게 만듭니다.

**주요 UI**
- 수행자, 이벤트 유형, 날짜 기준 필터
- 테이블 또는 타임라인
- 영향을 받은 리소스로 이동하는 링크

**예시 이벤트**
- 구독 일시중지
- 구독 해지
- 환불 승인
- 쿠폰 발급
- 결제 재시도
